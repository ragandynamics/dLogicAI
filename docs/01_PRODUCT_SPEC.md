# dLogicAI Product Specification
## Purpose
dLogicAI provides a secure, scalable conversational API that applications can integrate through web and mobile clients.

## Product Principles
- Tenant isolation by default.
- Provider abstraction rather than provider lock-in.
- Configurable pricing.
- Usage reserved before provider invocation.
- BYOK is optional, not the primary positioning.
- Free tier supported.
- Multi-language input/output.
- Transparent cost estimation.
- Add-ons and overages are separately billable.

## Core Capabilities
Authentication, organizations, projects, API keys, conversations, AI responses, usage/quota, billing, AI credits, BYOK, connectors, Chat Services, intelligence and observability.
